# SmartBridge Google OAuth Branding

Use these production values on the Google Auth Platform **Branding** page after Ticket 29 is deployed:

- App name: `SmartBridge Properties`
- App home page: `https://smartbridgeproperties.vercel.app`
- App privacy policy link: `https://smartbridgeproperties.vercel.app/privacy-policy.html`
- App terms of service link: `https://smartbridgeproperties.vercel.app/terms-of-service.html`
- Authorized domain: `smartbridgeproperties.vercel.app`
- Developer contact information: the Google account used to manage SmartBridge

Use the SmartBridge logo only if Google accepts it without requiring additional brand verification. The application requests only the standard OpenID Connect scopes used for name, email address, and profile information.
